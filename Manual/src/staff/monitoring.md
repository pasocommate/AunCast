# モニタリングと上限調整（スタッフ向け）

スタッフ画面では、インスタンス全体の再生・再同期の状況をリアルタイムに確認できます。これを随時確認することで、スタッフは[同時Resync上限](../concepts/connection-limit.md)を調整するなどの適切な対処ができます。

![スタッフ操作画面](../assets/portable-panel-staff.png){ width="360" }

---

## 画面の見方

### 状態インジケーター（右側の色付き表示）

全員の状態を **色** でまとめて示す領域です。全体が安定しているか、何が起きているかを一目で把握できます。色のおおよその意味は次のとおりです。

| 色 | 意味 |
|---|---|
| <span style="color:#DDDDDD">■</span> 白 | 正常に再生中 |
| <span style="color:#5599FF">■</span> 青 | 再同期の順番待ち |
| <span style="color:#FFCC33">■</span> 黄 | 再同期の実行中 |
| <span style="color:#FF8833">■</span> 橙 | 接続中（読み込み中） |
| <span style="color:#FF4444">■</span> 赤 | エラー |

記号の **塗り** は、その観客が再生中か停止中かを示します。

| 形 | 意味 |
|---|---|
| ■（塗り） | （現用系統が）再生中 |
| □（枠） | （両系統が）停止中 |

!!! tip "色による読み取りの要点"
    - **青が多い** → 多数が順番待ち。Resync Allの直後や、配信が乱れた直後に発生します。これが増え続けてなかなか減らないときは、同時Resync上限を増やすことを検討してください。
    - **赤が増加** → エラーが多発。配信元・配信サーバー・URLが正常かを確認してください。
    - **黄が多い** → 枠を最大限に使って順次処理中。これは正常な「混雑」状態です。

!!! note "配信を停止すると全員赤になります（正常）"
    OBSなどで配信（ソース）を停止すると、切断された各クライアントが再接続を試行し続けるため、インジケーターが **全員赤** になります。これは正常な動作です。配信を終えたら **Stop All** で停止してください（→ [配信・運用上の注意](streaming.md)）。

### 人数の表示（Playing / Instance / Queued）

| 表示 | 意味 |
|---|---|
| **Playing** | 現在再生中の人数 |
| **Instance** | インスタンス内の人数 |
| **Queued** | Resyncの順番待ちの人数 |

**Playing** の右に `+10` のような表示が付く場合、その数は **Resync中（待機系統の接続処理中）の人数** です。たとえば `80+10` は、80名が（現用系統で）再生中で、追加で10名が（待機系統で）接続処理中であることを示します。

このとき、**Queued** の待機人数表示の右側に `24s` のような秒数が表示されます。この秒数は、全体の再同期が完了するまでの目安です。

## 上限の調整 {#limits}

スタッフはその場で **Connections** と **Concurrent** を変更できます（変更は全員に反映されます）。それぞれ **Edit** ボタンで編集します。

数値の詳しい意味と考え方は[同時接続上限の管理](../concepts/connection-limit.md#limit-params)を参照してください。以下では、運用中の画面を見てどのように値を調整すべきかを示します。

### 増減の目安

| 状況 | 対応 | 理由 |
|---|---|---|
| Resync Allの完了が遅すぎる | Concurrent を **上げる** | 一度に処理できる人数が増え、早く完了する |
| エラー（赤）が増えた | Concurrent を **下げる** | 配信サーバーへの一度の負荷を減らし、成功率を上げる |
| 配信プランの異なるサーバーに接続した | Connections を更新 | 計算の基準を実態に合わせる |

!!! warning "上げすぎに注意"
    Concurrent を空き接続より大きくすると、再同期で配信サーバーの上限を超過し、**かえって失敗が増えます**。「早く完了させたい」からと上げすぎないでください。判断に迷う場合は下げるほうが安全です。

## 異常な状況への対処

| 画面の状況 | 想定される原因 | 対応 |
|---|---|---|
| 赤が散発的 | 一部の観客の一時的なエラー | 経過観察。各自の Resync で復旧することが多い |
| 赤が広範囲・増加が続く | 配信停止時（正常）／配信元・配信サーバー・URLの問題 | Playing を確認しURLを入れ直すか Reboot All（配信停止後は Stop All） |
| 青が多く減らない | 順番待ちが滞留 | Concurrent を上げる。配信サーバーに余裕があるか確認 |

操作方法は[操作パネルの使い方](operations.md)を参照してください。

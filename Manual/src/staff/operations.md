# 操作パネルの使い方（スタッフ向け）

このページは、配信を運営するスタッフが使う操作画面（スタッフビュー）の使い方を説明します。背景は[再同期の仕組み](../concepts/resync.md)と[同時接続上限の管理](../concepts/connection-limit.md)を読んでおくと、判断がしやすくなります。

スタッフビューはこんな画面です。

![スタッフ操作画面](../assets/portable-panel-staff.png){ width="360" }

---

## スタッフ画面を開く（解錠） {#unlock}

スタッフ画面は、許可された人だけが開けます。開き方は 2 通りです。

1. **名前で許可されている**：ワールド設置者がスタッフの名前を登録しておくと、その人は解錠なしでスタッフ画面を使えます。
2. **暗証番号で解錠する**：壁のパネルのカギのアイコンから、**4 桁の暗証番号** を入力して解錠します。

![壁のパネル（暗証番号の入力）](../assets/wall-panel-staff-passcode.png){ width="260" }

解錠したあとは、手元パネルに出る **切り替えボタン** でスタッフ画面に移れます。

!!! note "暗証番号の解錠は『自分の端末だけ』"
    暗証番号で解錠しても、ほかの人の画面には影響しません。別の端末では、また解錠が必要です。

---

## 配信 URL を変える（Next URL → Promote）

配信のアドレス（URL）を設定・変更する操作です。

1. **Next URL** の入力欄に、新しい配信 URL を入れる。
2. 右の **送信ボタン**（矢印）を押す。

これで URL が **全員に反映** され、各視聴者が新しい配信を再生し始めます。いま流れている URL は **Playing** の欄で確認できます。

!!! info "おかしな URL は弾かれます"
    URL の形が明らかに正しくない場合は反映されません。

!!! warning "誰かが再同期している最中の変更について"
    再同期中の人がいるときに URL を変えると、その人は再同期をやめて新しい URL で再生し直します。意図して切り替えてください。

---

## Resync All（全員一斉の再同期） {#global-resync}

**Resync All** ボタンを押すと、インスタンス内の全員を一斉に再同期します。

ただし「一斉」といっても、全員が同時につなぎ直すわけではありません。**ふつうの再同期と同じ順番待ちの列に、全員がまとめて並ぶ** だけで、「同時にやってよい人数」の枠ぶんずつ順番に片付きます。だから[配信サーバーの上限を超えません](../concepts/connection-limit.md#staggering)。

!!! tip "押すタイミングのコツ"
    Resync All は **曲間・トーク中・暗転など、多少の途切れが目立たない瞬間** に押すのがコツです。全体のズレ（Drift）がじわじわ溜まってきたときや、配信が一度乱れて全員をそろえ直したいときに使います。全員終わるまでの目安時間は[モニタリング画面](monitoring.md)で確認できます。

---

## Stop All（全員の再生を止める）

**Stop All** で、全員の再生をすぐに止めます。配信終了時や、間違った配信を流してしまったときの緊急停止に使います。停止中、各画面は待機用の画像に戻ります。

---

## Reboot All（全員の強制リブート） {#force-reboot}

**Reboot All** は、全員の映像をいったん全部止めて、つなぎ直させる緊急操作です。

!!! danger "ふだんは使いません"
    Reboot All は、なめらかな切り替えではありません。**全員の映像・音が一度途切れます。** Resync All で直らない深刻な不調（多くの人が止まってしまっているなど）のときの、最後の手段です。まず Resync All を試し、それでもダメなときだけ使ってください。

| 操作 | 途切れ | 用途 |
|---|---|---|
| **Resync All** | ほぼなし（裏で切り替え） | ふだんの全員一斉の再同期。まずはこちら |
| **Reboot All** | あり（全部止めてつなぎ直す） | 深刻な不調のときの最後の手段 |

---

## 接続上限を変える（Connections / Concurrent）

スタッフ画面では、接続管理の 2 つの数字をその場で変更できます（変更は全員に反映されます）。

- **Connections（接続数）**：配信サーバーが受け付けられる上限人数。契約プランに合わせます。
- **Concurrent（同時実行数）**：同時に再同期してよい人数。今の混み具合を見て調整します。

それぞれ右の **Edit** ボタンを押すと編集できます（増減して確定）。

数字の決め方や調整のコツは次のページにまとめています。

[→ モニタリングと上限調整へ](monitoring.md)

## ヘルプと言語

各ボタンにカーソル（VR はポインタ）を合わせると、画面に説明が出ます。説明欄を押すと **日本語 / 英語** を切り替えられます。

## 操作の早見表

| やりたいこと | 操作 | 途切れ |
|---|---|---|
| 配信 URL を変える | Next URL に入力 → 送信 | 切り替え時に各自が再生開始 |
| 全体のズレをそろえ直す | **Resync All** | ほぼなし |
| 配信を止める | **Stop All** | 停止 |
| 深刻な不調から立て直す | **Reboot All** | あり |
| 同時に再同期する人数を変える | **Concurrent** の Edit | — |
| 配信プランに合わせる | **Connections** の Edit | — |

# トラブルシューティング / FAQ

困りごとを立場別にまとめます。操作の詳しい説明は[視聴者ガイド](../viewer/panel.md) / [スタッフガイド](../staff/operations.md)を参照してください。

---

## 視聴者向け

### 映像が止まった・カクつく

まず **手元パネルの Resync ボタン** を押してください。順番待ちになっても、待っていれば再同期されます。直らない・順番が一向に来ないときは **緊急リブート**（途切れますが自分でつなぎ直す）を試します。

### 音が出ない・音がズレている

**Resync ボタン** が有効です。**Drift メーター** が溜まっているなら、再同期でズレがリセットされます。あわせて、**Volume を 0（消音）にしていないか** も確認してください。

### 曲間や静かな場面で勝手に再同期される

無音のときの自動再同期が働いています。手元パネルの **[Auto Resync をオフ](../viewer/status.md#auto-silence)** にすると、無音をきっかけにした自動再同期だけを止められます（映像が止まったときの自動再同期や、手動の Resync は引き続き使えます）。

### Resync ボタンが押せない

何も再生していないとき（停止中など）は押せません。スタッフが配信を流しているか確認してください。再同期した直後は、しばらく押せない時間があります。

### 「再接続待機中」「問題が発生しています」と出る

うまくつながらない状態です。AunCast は少し待ってから自動で何度もつなぎ直します。長引くときは配信側の問題が考えられるので、スタッフに状況を伝えてください。

### パネルの呼び出し方が分からない

呼び出し方は壁のパネルの **Spawn Gesture** で選べます（VR はスティックやトリガーの操作、デスクトップは Tab / F5 / Esc のいずれか）。壁のパネルの **Spawn Panel** ボタンからも出せます。

## スタッフ向け

### スタッフ画面が開けない

- 名前で許可されているか、または **壁のパネルで暗証番号を解錠** したか確認します。
- 解錠後は、手元パネルの **切り替えボタン** でスタッフ画面に移ります。
- 暗証番号の解錠は端末ごとです。別の端末では、また解錠が必要です。

### URL を変えても再生されない

- URL の形が正しいか確認します（おかしな URL は反映されません）。
- **Playing** の欄に、意図した URL が反映されているか確認します。
- 配信側が実際に映像を出しているか（配信サーバー・配信ソフトなど）を確認します。

### エラー（赤）が増える

配信サーバーへの負荷が高い可能性があります。**Concurrent（同時実行数）を下げて** ください。空き席より大きくしていないかも確認します（[上限調整](../staff/monitoring.md#limits)）。

### Resync All の完了が遅い

順番待ちが多い状態です。配信サーバーに余裕があれば **Concurrent を上げる** と速くなります。ただし上げすぎると失敗が増えるので、エラー（赤）を見ながら調整します。

### 全員の映像がまとめて止まった

配信元・配信サーバー・URL の問題が疑われます。**Playing** を確認し、必要なら URL を入れ直します。それでも直らない深刻なときは、最後の手段として **Reboot All**（全員途切れます）を使います。

## 設置者向け

### 停止時に画面が白く（黒く）なる

停止中の待機用画像が設定されていません。`AunCastSettings.idleScreenTexture` を設定してください（[導入とパラメータ設定](../setup/install.md#スクリーンの配置)）。

### スクリーンを増やしたのに映らない

スクリーンを追加したら、`AunCastSettings` の **「`AunCastEventBus` 参照を再配線」** を実行して、表示先をつなぎ直す必要があります。

### 何人まで耐えられる？

配信サーバーの上限しだいです。**Connections** を契約プランの人数に合わせ、**Concurrent** は空き席から余裕を見て決めます。考え方は[同時接続上限の管理](../concepts/connection-limit.md)を参照してください。

## よくある質問（FAQ）

??? question "再同期すると、全員の映像がそろうの？"
    いいえ。再同期は **ひとりひとりが自分の映像を立て直す** ものです。みんなの再生位置をぴったり合わせる機能ではありません。Resync All も「各自が順番に立て直す」だけです。

??? question "なぜ再同期は順番待ちになるの？"
    全員が一斉につなぎ直すと、配信サーバーの上限を超えて、かえって不安定になるからです（[同時接続上限の管理](../concepts/connection-limit.md)）。

??? question "緊急リブート（Reboot All）と再同期（Resync）は何が違う？"
    再同期は予備を裏で準備してからそっと切り替えるので **ほぼ途切れません**。緊急リブートはいったん全部止めてつなぎ直すので **途切れます**。緊急リブートは最後の手段です。

??? question "音量を変えたら、ほかの人にも反映される？"
    いいえ。Volume は自分の端末だけの設定で、ほかの人や配信そのものには影響しません。

??? question "ライブ配信じゃなく録画動画でも使える？"
    使えますが、AunCast はライブ配信向けに作られています。巻き戻しができる録画動画では、ふつうのプレイヤーのほうが向く場面もあります。

# 用語集

マニュアルやパネルに登場する用語をまとめます。

## 再生・再同期

**再同期（Resync）**
: 停止・ズレが生じた配信を、滑らかに復旧すること。AunCast の中心機能です。詳細は[再同期の仕組み](../concepts/resync.md)。

**現用系統 / 予備系統**
: AunCast は観客ごとに配信の再生系統を２系統保持します。現在再生中の側が「現用系統」、必要時に使用する側が「予備系統」です。

**Drift**
: 自分の再生と配信元との「ズレの蓄積量」。蓄積が進むと自動で再同期します。

**Audio Level**
: 現在 音声が出ているかを示すメーター。無音が続くと自動で再同期します。

**Silence Resync**
: 無音が続いたときに自動で再同期するかどうかの切り替え。観客が任意にオン／オフできます。

**緊急リブート / Reboot All**
: いったんすべて停止して接続し直す最終手段。滑らかではなく一度途切れます。通常は使用しません。

## 順番待ち

**順番待ち**
: 再同期は一斉には実行せず、列に並んで順番を待ちます。配信サーバーの過負荷を防ぐための仕組みです。

**順番を管理する仕組み（コーディネーター）**
: ワールドに１つ存在し、誰がいつ再同期してよいかの順番を管理します。

**Resync All**
: スタッフが全員を一斉に再同期させる操作。実体は「全員が順番待ちの列にまとめて並ぶ」ことです。

**見込み時間 / ETA**
: 自分（または全体）の再同期が完了するまでの、おおよその残り時間。

## 接続

**配信サーバー**
: ライブ配信を各観客へ届けるサーバー（例: VRCDN）。同時接続数に上限があります。

**Connections（同時接続上限）**
: 配信サーバーが受け付けられる上限接続数。契約プランに合わせる値です。

**Concurrent（同時Resync上限）**
: 同時に再同期してよい人数。混雑状況を見てスタッフが調整します。

## パネル

**手元パネル**
: 観客が呼び出して手元で使うメニュー。状態確認と操作の中心です。

**壁のパネル**
: ワールドに固定設置された操作パネル。近づくと表示が切り替わります。

**スタッフ画面**
: URL変更・全員一斉の再同期・停止・上限調整などを行う、スタッフ用の画面。

**Stop All**
: 全員の再生を停止する操作。

**Spawn Panel / Spawn Gesture**
: 手元パネルを呼び出すボタン（Spawn Panel）と、その呼び出し方法を選択する設定（Spawn Gesture）。

## 環境・操作

**ローカル**
: 自分の VRChat クライアント内のみ、という意味。ローカル設定は同期されず、他の観客には影響しません（例: 音量、Silence Resync、暗証番号の解錠）。

**VRChat ディスプレイネーム**
: VRChat 上の表示名。スタッフ許可リストはこの名前で指定します。

**HUD**
: VRで視界に重ねて表示される情報。呼び出しジェスチャーの長押し中に表示される進捗（HUDゲージ）などに使用します。

**インスタンス**
: 同一のワールドに集まっている１つのルーム。接続上限や人数はこのインスタンス単位で考えます。

## 再生ステータス表示（パネルに表示される状態）

| 表示の意味 | 状態 |
|---|---|
| 待機中 | まだ再生していない |
| 再生中 | 正常に視聴できている |
| 再同期 待ち | 順番待ち中 |
| 再同期 中 | 背後で復旧している最中 |
| 再接続待機中（あと○秒） | 復旧できず、少し待って再試行しようとしている |

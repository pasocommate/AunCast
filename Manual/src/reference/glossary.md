# 用語集

マニュアルやパネルに出てくる言葉を、やさしくまとめます。

## 再生・再同期のこと

**再同期（さいどうき / Resync）**
: 止まったりズレたりした映像を、なめらかに立て直すこと。AunCast の中心の機能です。詳しくは[再同期の仕組み](../concepts/resync.md)。

**いま映している側 / 予備の側**
: AunCast はひとりにつき映像プレイヤーを 2 つ持ちます。今見えているのが「いま映している側」、いざというときに使うのが「予備の側」です。

**Drift（ドリフト）**
: 自分の映像と配信元との「ズレの溜まり具合」。溜まりすぎると自動で再同期します。

**Audio Level（オーディオレベル）**
: 今ちゃんと音が出ているかを示すメーター。無音が続くと自動で再同期します。

**Auto Resync（オートリシンク）**
: 無音が続いたときに自動で再同期するかどうかの切り替え。視聴者が自分でオン／オフできます。

**緊急リブート / Reboot All**
: いったん全部止めてつなぎ直す、最後の手段。なめらかではなく一度途切れます。ふだんは使いません。

## 順番待ちのこと

**順番待ち**
: 再同期は早い者勝ちで一斉には始めず、列に並んで順番を待ちます。配信サーバーをパンクさせないための仕組みです。

**順番を管理するしくみ（コーディネーター）**
: ワールドに 1 つだけあり、誰がいつ再同期してよいかの順番を管理します。

**Resync All（リシンクオール）**
: スタッフが全員を一斉に再同期させる操作。中身は「全員が順番待ちの列にまとめて並ぶ」だけです。

**見込み時間 / ETA**
: 自分（または全体）の再同期が終わるまでの、だいたいの残り時間。

## 接続のこと

**配信サーバー（CDN）**
: ライブ映像を各視聴者に届けるサーバー（例: VRCDN）。受け入れ人数に上限があります。

**Connections（コネクションズ／接続数）**
: 配信サーバーが受け付けられる上限人数。契約プランに合わせる数字です。

**Concurrent（コンカレント／同時実行数）**
: 同時に再同期してよい人数。混み具合を見てスタッフが調整します。

## パネルのこと

**手元パネル**
: 視聴者が呼び出して目の前で使うメニュー。状態確認と操作の中心。

**壁のパネル**
: ワールドに固定設置された操作板。近づくと表示が変わります。

**スタッフ画面**
: URL 変更・全員一斉の再同期・停止・上限調整などを行う、スタッフ用の画面。

**Stop All（ストップオール）**
: 全員の再生を止める操作。

**Spawn Panel / Spawn Gesture**
: 手元パネルを目の前に出すボタン（Spawn Panel）と、その呼び出し方を選ぶ設定（Spawn Gesture）。

## パネルに出る状態の文字

| 表示の意味 | どんな状態か |
|---|---|
| 待機中 | まだ再生していない |
| 再生中 | ふつうに見られている |
| 再同期 待ち | 順番待ち中 |
| 再同期 中 | 裏で立て直している最中 |
| 再接続待機中（あと○秒） | うまくいかず、少し待ってまた試そうとしている |

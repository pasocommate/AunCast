# 設定と調整（スタッフ向け）

このページは、AunCast をシーンに配置した後に行う設定・配線・アクセス制御・運用値調整の詳細説明です。導入の最短手順は[クイックスタート](../quickstart.md#setup)を参照してください。

設定はすべて、AunCast ルートにある **`AunCastSettings` コンポーネントの専用インスペクタ**で一括編集します。各コンポーネントへの値の反映（配線）も、このインスペクタのボタンで実行します。

---

## 1. `AunCastSettings` インスペクタの構成

AunCast ルートの **`AunCastSettings`** を選択すると、専用インスペクタが次のセクションで表示されます。

- **壁パネル配線** … EventBus / 各パネル / スクリーンの参照を再配線するボタン
- **AVPro Speaker 配線** … 音声出力（AudioSource）のセットアップ
- **映像プレイヤー** … 解像度・低遅延・クロスフェード・停止中の画像
- **UI / 操作** … 音量・呼び出しジェスチャー・HUD・壁パネル距離・スタッフ許可・パスコード
- **再生監視** … 無音検知・停止検知・ドリフト
- **Resync制御** … 同時接続制限・リトライ / クールダウン
- **デバッグ** … タイムラインログ

!!! tip "ラベルの内部名を確認したいとき"
    インスペクタのラベルにカーソルを合わせて **Altキーを押す**と、内部の変数名が表示されます。ラベルを右クリックすると変数名をコピーできます（不具合報告やスクリプト連携の際に便利です）。

---

## 2. スクリーンを増やす {#screens}

映像の出力先（スクリーン）は複製できます。**同一のマテリアルを共有していれば、スクリーンを増やしてもビデオデコードの負荷はほぼ一定**です。

### スクリーンを複製する

スクリーンを増やす際は、既存の **`Screen` GameObject** を複製してください。複製すると `VideoMeshScreen` の設定がそのまま引き継がれます。

1. 既存の **`Screen` GameObject** を複製し、ワールド内の任意の位置・サイズに配置します。
2. `AunCastSettings` の **壁パネル配線** にある **「AunCastEventBus参照を再配線」** を押し、コンポーネントを関連付けます。

別のシェーダー / マテリアルを使用する場合は、複製した `VideoMeshScreen` の次の項目を合わせてください。

- **テクスチャパラメータ名**（`texParam`、既定 `_EmissionMap`）… そのシェーダーが映像に使用するテクスチャプロパティ名
- **レンダラーインデックス**（`rendererIndex`）… マルチマテリアルのどのスロットに適用するか

!!! note "停止中の画像（アイドル画像）"
    再生停止中の表示は、**映像プレイヤー** セクションの **「停止中のスクリーン画像」** で指定します。再配線の際に各スクリーンへ転写されます。

## 3. 音声（AVPro Speaker 配線）

AunCast は内部に `PlayerA` / `PlayerB`（A/B再生系統）を持つため、音声出力にもそれぞれ専用の `AudioSource` が必要です。これは **AVPro Speaker 配線** ツールが半自動で用意します。

### 手順

1. 音声出力の基準にする **VRC AVPro Video Speaker＋AudioSource** を用意し、**位置・空間音響（3D設定）・AudioSource の音量**を任意に設定します。既存のものがあれば、そのまま使用できます。
2. `AunCastSettings` の **AVPro Speaker 配線** セクションを確認します。シーン上のスピーカーが **「検出対象」** に一覧表示されます。
3. **「AVPro Speaker 出力先セットアップを実行」** を押します。

このボタンは、検出した「スピーカー＋AudioSource」を **Player A / B（A/B再生系統）用に複製**し、各複製の出力先（videoPlayer）をA / Bに配線し、無音検知用の AudioSilenceDetector を付与したうえで、**元のオブジェクトを無効化（EditorOnly タグ）**します。

### 音量と既存 AudioSource の扱い

- 複製は **元の AudioSource をそのまま複製**します。すなわち、**元のスピーカーで設定した音量・3D設定が、そのままA / Bへ引き継がれます**。音量バランスは、セットアップの実行前に元の AudioSource 側で決めておいてください。
- 観客がパネルで変更する音量は **ローカル**設定で、ここで決めた AudioSource の音量に乗算されます。基準となるバランスはこの AudioSource 側で決まります。
- **複数スピーカーの多点配置**も可能です。検出された各スピーカーがA / B両方へ複製されます。
- 設定をやり直す場合は、再度ボタンを押すと、生成済みコンテナ（`AunCastSpeakerRefs_A` / `_B`）をクリアして作り直します。
- A / Bで同一 AudioSource を共有しているなどの配線不整合は、ツールが自動で検査し、赤色で表示します。

## 4. 接続上限の設定（最重要） {#connection-limits}

配信サーバーの同時接続上限に合わせた設定は、AunCast 運用の要です。考え方は[同時接続上限の管理](../concepts/connection-limit.md)を必ず確認してください。**Resync制御 → 同時接続制限** の次の２項目を設定します。

| インスペクタ表示名 | 設定方針 |
|---|---|
| **同時接続上限** | 契約している **配信プランの同時接続上限** を入力する（例: 100） |
| **同時Resync上限 [人]** | 想定インスタンス人数での空き枠から、余裕を見た値（**10** 程度が出発点） |

どちらも **スタッフがワールド内で実行中に変更可能**です（スタッフ画面の Connections（同時接続上限） / Concurrent（同時Resync上限））。初期設定時に妥当な値を入力し、本番ではスタッフが調整します（[モニタリングと上限調整](monitoring.md#limits)）。

!!! warning "自動再生は原則オフ推奨・運用上の注意"
    「最初のJoinで自動再生」を有効にすると、別インスタンスが立てられるだけで自動的に配信へ接続し、同時接続数が超過し得ます。**原則として自動再生は使用しない**ことを推奨します。CDNの選定・ビットレート・URLの取り扱いも含め、運用上の注意は [配信・運用上の注意](streaming.md) を必ず確認してください。

## 5. アクセス制御（スタッフ権限）

スタッフ画面を使用できるユーザーを制限します。**UI / 操作** セクションで設定します。

- **スタッフ許可ユーザー名** … パスコードなしでスタッフ権限を付与する **VRChat ディスプレイネーム** のリスト。配信管理を担当するスタッフを登録します。
- **壁パネル解錠パスコード** … 壁パネルから入力してスタッフ画面を解錠する４桁数字。空欄で無効。当日のヘルプには口頭でパスコードを伝える、といった運用ができます。

両者は併用できます。

## 主要パラメータ早見表

設定変更は `AunCastSettings` インスペクタで行います。

### 映像プレイヤー

| 表示名 | 既定 | 意味 |
|---|---:|---|
| 最大解像度 | 720p | AVProビデオプレイヤーの最大解像度（360p〜2160p） |
| 低遅延モード | オン | AVPro の低遅延モード |
| クロスフェード時間 [秒] | 0.3 | 切替時の音声クロスフェード長 |
| 停止中のスクリーン画像 | 未指定 | 停止時に表示する固定画像 |

### UI / 操作

| 表示名 | 意味 |
|---|---|
| 初期音量 | 各ユーザーの起動時ローカル音量（０〜１） |
| デフォルト配信URL | Next URL欄の初期値（最初のJoin時の自動再生にも使用） |
| 最初のJoinで自動再生 | 最初のユーザー入室時にデフォルトURLを自動再生 |
| VR / デスクトップ 呼び出しジェスチャー初期値 | HUD（手元パネル）呼び出し方法の初期有効設定 |
| ジェスチャー保持時間 [秒] | 長押し系ジェスチャーの必要保持時間 |
| ジェスチャーHUD表示猶予 [秒] | HUDプログレスを出し始めるまでの猶予 |
| HUD配置オフセット (VR) / (Desktop) | HUDの表示位置オフセット |
| パネル自動閉じ距離 [m] | 手元パネルから離れると自動で閉じる距離（０で無効） |
| パネル視界外閉じ [秒] | 手元パネルが視界外に出てから閉じるまでの秒数（０で無効） |
| 壁パネル近距離 / 遠距離 [m] | 壁パネルの表示が切り替わる内側 / 外側のしきい値 |

### 再生監視 → 無音検知

| 表示名 | 既定 | 意味 |
|---|---:|---|
| RMS閾値 [dBFS] | -60 | 無音と判定する音量しきい値（０ dBFS = フルスケール） |
| 継続秒数 [秒] | 2.0 | 無音がこの秒数続いたら再同期 |
| 抑止時間 [秒] | 150 | 再同期後に無音検知を再開するまでの時間 |
| ピーク保持 [秒] / ピーク減衰 [dB/秒] | — | Audio Level メーターのピーク表示の挙動 |

### 再生監視 → 停止検知

| 表示名 | 既定 | 意味 |
|---|---:|---|
| タイムアウト [秒] | 2.0 | この時間 前進しなければ停止と判定 |
| ポーリング間隔 [秒] | 0.1 | 再生位置を監視する間隔 |
| 前進判定閾値 [秒] | 0.01 | 前進とみなす最小の変化量 |
| 最小連続前進回数 [回] | ５ | 生存とみなす連続前進回数 |

### 再生監視 → ドリフト

| 表示名 | 既定 | 意味 |
|---|---:|---|
| Resync閾値 [秒] | 0.1 | 蓄積ドリフトがこれを超えたら自動再同期 |
| 平滑化時定数 [秒] | 1.5 | ドリフト平滑化の時定数 |
| 猶予時間 [秒] | 5.0 | 再生開始直後にドリフト判定をしない猶予 |

### Resync制御 → 同時接続制限

| 表示名 | 既定 | 意味 |
|---|---:|---|
| 同時Resync上限 [人] | 10 | 同時に再同期してよい人数の初期上限 |
| 同時接続上限 | 100 | 配信サーバーへの同時接続上限の初期値 |
| 接続開始待ち [秒] | 10 | 許可後、接続が始まるまでの最大待機 |
| 実行時間の上限 [秒] | 50 | １回の再同期に許される最大時間 |

### Resync制御 → リトライ / クールダウン

| 表示名 | 既定 | 意味 |
|---|---:|---|
| 切替完了タイムアウト [秒] | 45 | 許可〜切替完了までの全体制限 |
| 読込後の待機 [秒] | ５ | 読み込み後、次の再同期を受け付けるまでの待機 |
| リトライ間隔（初回） [秒] | ５ | 両系統失敗時のリトライ基本間隔 |
| リトライ間隔倍率 | 1.5 | 連続失敗ごとにリトライ間隔へ掛ける倍率 |
| リトライ間隔（上限） [秒] | 90 | リトライ間隔の頭打ち値 |

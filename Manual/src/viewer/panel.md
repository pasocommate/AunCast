# パネルの呼び出しと操作（視聴者向け）

このページは、ワールドに来た視聴者（観客）が使うパネルと、その操作を説明します。先に[再同期の仕組み](../concepts/resync.md)を読んでおくと、各ボタンの意味がすぐ分かります。

視聴者が使うパネルは 2 つあります。

- **手元パネル**：自分で呼び出して、目の前に出して使うメニュー。状態の確認と操作の中心です。
- **壁のパネル**：ワールドに固定で設置されている操作板。近くに行って使います。

---

## 手元パネルを呼び出す

手元パネルは、いつでも自分の目の前に出せるメニューです。呼び出し方は、壁のパネルの **「Spawn Gesture」** で選べます。

=== "デスクトップ"

    キーボードのキーで呼び出します。下のどれか 1 つを選びます。

    - **Double-tap Tab** … Tab キーを続けて 2 回押す
    - **Double-tap F5** … F5 キーを続けて 2 回押す
    - **Hold Esc** … Esc キーを押し続ける

    ![壁のパネル（デスクトップの呼び出し設定）](../assets/wall-panel-user-desktop.png){ width="300" }

=== "VR"

    コントローラーの操作で呼び出します。下のどれか 1 つを選びます。

    - **Hold Right Stick Up** … 右スティックを上に倒し続ける
    - **Hold Both Triggers** … 両手のトリガーを同時に握り続ける
    - **Double-tap Trigger (L) / (R)** … 左／右のトリガーを続けて 2 回引く

    ![壁のパネル（VR の呼び出し設定）](../assets/wall-panel-user-vr.png){ width="280" }

!!! tip "押し続けるタイプは HUD ゲージが出ます"
    「倒し続ける」「握り続ける」タイプの呼び出しでは、成立するまでの進み具合が **HUD ゲージ**（視界内の表示）で出ます。途中でやめればキャンセルされます。

!!! note "VR ではパネルを掴んで動かせます"
    出てきたパネルに手を近づけて **グリップ（握る）** すると、手に持って好きな場所へ動かせます。離すとその場所に留まります。

## 手元パネルでできること

呼び出すと、こんなパネルが出ます。

![手元パネル（視聴者ビュー）](../assets/portable-panel-viewer.png){ width="360" }

主な部品は次のとおりです。表示の詳しい読み方は[状態表示の見方](status.md)を参照してください。

| 部品 | できること |
|---|---|
| **Resync ボタン**（右下の青いボタン） | 自分の映像を再同期する（下記） |
| **緊急リブートボタン**（左下のオレンジの稲妻） | いったん全部止めてつなぎ直す最後の手段（下記） |
| **Drift** | 配信元との「音や映像のズレ具合」のメーター |
| **Audio Level** | いま音が出ているかを示すメーター |
| **Auto Resync** | 無音のときに自動で再同期するかの切り替え |
| **Volume** | 自分だけの音量（ほかの人には影響しません） |
| **左上のサムネイル下の文字** | 今の自分の状態（例: Idle ＝ 待機中） |
| **右上の × ボタン** | パネルを閉じる |

ここでは特に大事な 2 つのボタンを説明します。

### Resync ボタン {#resync-button}

押すと「再同期したい」と **順番待ちの列に並びます**。順番が来ると裏で新しい接続が用意され、準備ができたらなめらかに切り替わります（仕組みは[再同期の仕組み](../concepts/resync.md)）。

- 何も再生していないとき（停止中など）は押せません。
- 押した直後やしばらくの間は、**「あと何秒で順番が来そうか」** が表示されます。
- 順番待ちが長くても、基本は待っていれば順番が回ってきます。待てないときは緊急リブートを検討します。
- 順番待ちの間にもう一度押すと、**取り消し** できます。

### 緊急リブートボタン {#reboot}

順番待ちをせずに、**自分の映像をいったん全部止めて、すぐにつなぎ直す** 最後の手段です。いつでも押せます。

!!! danger "これは画面が途切れます"
    緊急リブートは、なめらかな切り替えではありません。**映像も音も一度途切れます。** まずは通常の **Resync ボタン** を試し、それでも直らない・順番が一向に来ないときだけ使ってください。実行後はしばらく再同期を控える時間に入ります。

## 壁のパネル

ワールドに固定設置された操作板です。**近づくと表示が自動で変わります。**

=== "離れているとき"

    画面いっぱいの **大きな Resync ボタン** になります。誰でも押せて、遠くからでも再同期できます。

    ![壁のパネル（大きな Resync ボタン）](../assets/wall-panel-resync-only.png){ width="260" }

=== "近づいたとき"

    こまかい操作ができる表示になります。

    - **Resync ボタン** … 自分を再同期する
    - **緊急リブートボタン**（オレンジの稲妻）… 上記の最後の手段
    - **Spawn Panel ボタン** … 手元パネルを目の前に呼び出す
    - **Spawn Gesture** … 手元パネルの呼び出し方を選ぶ（上記）

    ![壁のパネル（近づいたとき）](../assets/wall-panel-user-desktop.png){ width="300" }

!!! info "スタッフ用の入口もここにあります"
    右下のカギのアイコンから、スタッフが暗証番号を入れて操作画面を開く入口（Staff ビュー）に入れます。視聴者の操作には関係ありません。くわしくは[スタッフガイド](../staff/operations.md#unlock)を参照してください。

---

## こんなときどうする（早見表）

| 状況 | おすすめ操作 |
|---|---|
| 映像が止まった／カクつく | まず **Resync ボタン**。待っていれば順番が来る |
| 音が出ない／音がズレている | **Resync ボタン**（Drift メーターが溜まっているなら特に効く） |
| Resync しても直らない／順番が来ない | **緊急リブート**（途切れるのを承知で） |
| 曲間など、静かな場面で勝手に再同期される | パネルの [Auto Resync をオフ](status.md#auto-silence) |
| 音量を変えたい | パネルの **Volume**（ローカル＝自分だけに反映） |

次は、パネルに並ぶメーターや状態表示の読み方を見ていきます。

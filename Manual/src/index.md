# AunCast ユーザーマニュアル

**AunCast** は、VRChat ワールド向けの **低遅延ライブ配信専用** 動画プレイヤーシステムです。ライブ配信を長時間視聴し続けるうちに起きる「映像の停止」「音ズレ（ドリフト）」「無音化」を、視聴を止めずに復旧させることを目的にしています。

!!! abstract "このマニュアルで分かること"
    - AunCast が普通の動画プレイヤーと **何が違うのか**
    - ワールド設置者として **どう導入し、どのパラメータを調整するか**
    - スタッフとして **配信をどう運用し、接続上限をどう管理するか**
    - 視聴者として **パネルをどう使い、状態表示をどう読むか**

---

## 普通の動画プレイヤーと何が違うのか

VRChat の一般的な動画プレイヤーは「URL を 1 本読み込んで再生する」だけのものがほとんどです。録画済み動画ならそれで十分ですが、**低遅延ライブ配信**では次の問題が起きます。

- ライブ配信は巻き戻し・シークができず、一度止まると **そのまま止まりっぱなし** になりやすい
- 再生し続けるうちに、配信元との時刻が少しずつズレて **音ズレ（ドリフト）** が蓄積する
- 直そうとして読み込み直すと、**映像・音声が一度途切れる**

AunCast は、この問題を解決するために他のプレイヤーにはない 2 つの仕組みを持っています。**この 2 つを理解することが、AunCast を使いこなす鍵** です。

!!! note "① 再同期 (Resync) の仕組み"
    内部に **2 つのプレイヤー** を持ち、片方を裏で先に準備してからそっと切り替えます。単純な「読み込み直し」より途切れを抑えて、止まった映像を立て直します。

    [→ 仕組みを読む](concepts/resync.md)

!!! note "② 同時接続上限の管理"
    配信サーバーには **受け入れ人数の上限** があります。全員が一斉に再同期するとこの枠を食いつぶすため、AunCast は再同期を **順番待ち制** にして上限を超えないようにします。

    [→ 仕組みを読む](concepts/connection-limit.md)

!!! tip "まずはここから"
    AunCast を初めて触るなら、まず上の 2 ページを読むことを強くおすすめします。設置者・スタッフ・視聴者のどの立場でも、この 2 つの前提知識があると操作の意味がすぐ分かります。

## 読者別ガイド

このマニュアルは、最初に読んでワールドへ導入し、スタッフや視聴者に使い方を案内する **設置者（制作者）** を起点に、**設置者 → スタッフ → 視聴者** の順で構成しています。立場ごとの入口は次のとおりです。

| あなたは… | 読むべきページ |
|---|---|
| ワールドに導入する **設置者（制作者）** | [導入とパラメータ設定](setup/install.md) |
| 配信を運営する **スタッフ** | [操作パネルの使い方](staff/operations.md) → [モニタリングと上限調整](staff/monitoring.md) |
| ワールドに来た **視聴者（観客）** | [パネルの呼び出しと操作](viewer/panel.md) → [状態表示の見方](viewer/status.md) |
| 用語や困りごとを調べたい | [用語集](reference/glossary.md) / [トラブルシューティング / FAQ](reference/troubleshooting.md) |

## 動作環境

| 項目 | 値 |
|---|---|
| パッケージ名 | `tokyo.chigiri.pasocommate.auncast` |
| バージョン | 3.0.0 |
| Unity | 2022.3 |
| 依存（VRChat SDK） | `com.vrchat.worlds >= 3.10.2` |
| 依存（フォント） | `net.narazaka.vrchat.tmp-fallback-fonts-jp >= 1.0.0` |
| 依存（描画） | `tokyo.chigiri.pasocommate.rendermate >= 3.0.0 < 4.0.0` |

!!! info "対応プレイヤー / プロトコル"
    内部では `VRCAVProVideoPlayer` を 2 系統使用します。低遅延ライブストリーム（主に `rtspt://` 系）を想定して設計されています。録画済み動画の再生にも使えますが、本領を発揮するのはライブ配信です。

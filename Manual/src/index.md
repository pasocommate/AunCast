# AunCast ユーザーマニュアル

**AunCast** は、VRChat ワールド向けの **低遅延ライブ配信システム** です。インスタンス内で出演者が行うアバターパフォーマンスに合わせて、**ライブ演奏・DJプレイなど** をワールド内に配信するイベントで、長時間にわたってズレず・途切れずに配信し続けることを目的としています。
